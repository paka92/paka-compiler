# two Ui values, a copy and an exit mid-text

Two `Ui` values of one app, and a copy that goes on apart from the value it was copied from, each
keep their own actions, so release replays each history from its launch (M7-11c). A key after the
`ExitWith(7)` of an earlier key in the same `ui_type` traps `assert` (spec/screens.md section 14);
release ends with status 7 there. The unfinished function example does not keep release from
building the app. Expected output is written by hand.
