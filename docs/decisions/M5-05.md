# M5-05 · Layout rules and units

Status: approved by the owner on 2026-10-13.

Base: the recorded M5-05 page in DECISIONS.md. All five points **stand** as recommended there.

## 1. Points

**1.1 Whole units, scaled.** Every size and position is an Int number of units. One unit is one
pixel at scale factor 1; the window multiplies by the scale factor only when drawing. Measured text
is rounded up to whole units.

**1.2 Width down, height up.** A parent hands each child a width; the child answers with its
height. A Button hugs its label plus inner space. Text, Input, Row and Col fill. In a Row, hugging
children take their width first and filling children share the rest equally.

```
Row 480 wide, gap 8, test measure 8 per character:
  Button "x"       x=0    w=32   (8 + 12 + 12)
  Text "buy milk"  x=40   w=384  (480 - 32 - 48 - 8 - 8)
  Button "del"     x=432  w=48   (24 + 12 + 12)
```

**1.3 Left; centred in rows.** In a Col each child starts at the left edge. In a Row each child is
centred top to bottom, an odd leftover unit going below. Text is left-aligned.

**1.4 Text always wraps to its width.** Lines are filled word by word at the text library's break
places; spaces at a break are not drawn. A word wider than the line is broken where it stops
fitting, at least one character per line. Height is lines times 20; an empty text is one line.

```
Text "buy milk and bread", width 100, 8 per character:
  line 1: "buy milk and"
  line 2: "bread"
  size: 100 wide, 40 high
```

**1.5 Content that does not fit sticks out; only the window cuts it.** Nothing shrinks and no
container clips. Later elements draw over earlier ones.

## 2. Rules that follow

- The root is handed the window's width and sits at 0,0 with no margin. The window opens 480 by 360
  units, can be resized, and is white where the tree does not reach. A resize lays the same tree out
  again without running the view.
- Counter at 480 wide, test measure: Text "0" at 0,0 480x20; Row at 0,28 480x32; Button "-" at 0,28
  32x32; Button "+" at 40,28 32x32; placeholder at 0,68 64x32; Col 480x100.
- The gap goes between each two present children only. A child left out by an `if` takes none;
  placeholders and error nodes count.
- Leftover width that does not divide gives earlier filling children one unit more.
- A filling child in a Row is never narrower than 40 units; the row overflows to the right instead.
- Heights: Text, lines times 20; Button and Input, 32; Row, its tallest child; Col, children plus
  gaps. An empty Row or Col is 0.
- A placeholder hugs: name width plus 24, 32 high. An error node fills, its message wrapped inside 6
  units on every side.
- An Input cuts its own text at its border, the one clip in M5. The text shifts left just enough to
  keep the cursor inside; the shift is not kept state.
- Text is measured with the default font at 14 units, at scale factor 1, rounded up, line height 20.
  Tests use the measure of 8 units per character, breaking at spaces only.
- Hit testing picks the last-drawn element whose rectangle holds the point, including parts that
  stick out of the parent. Row and Col are never hit themselves.
- Pointer positions are divided by the scale factor, rounding down, before hit testing.
- Rectangles are not part of the tree text; UI examples never see them.
