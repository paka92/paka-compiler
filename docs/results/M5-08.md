# M5-08 · Library trial results

The trial is `trial/gui`, a crate outside the workspace with its own lock file. It opens one window
holding a text field, an `Add` button and a status line, drawn with M5-04's looks.
`unsafe_code` is forbidden in it.

- vello_cpu draws the screen into a pixmap, and the pixmap is copied into a softbuffer surface.
- Text is shaped and laid out by parley from one font file, with no system font lookup.
- AccessKit receives the element tree through accesskit_winit.
- `--png FILE` draws the same screen without a window, through a PNG encoder written with the
  standard library only.

Commands, run in a GNOME Wayland session (GNOME Shell 50, IBus running):

```
cargo test  --manifest-path trial/gui/Cargo.toml --locked --offline
cargo run   --manifest-path trial/gui/Cargo.toml --locked --offline -- --seconds 5
cargo run   --manifest-path trial/gui/Cargo.toml --locked --offline -- --png out.png --scale 2
```

For the screen-reader check, the trial ran inside `dbus-run-session` with an in-memory settings
backend. There, a private AT-SPI bus had accessibility switched on, and a pyatspi script read the
tree and invoked actions. The desktop's own accessibility setting was not changed.

| Check | Result |
|---|---|

| Unit tests: pixel colours at scale 1 and 2, layout, tree, actions, PNG bytes | 8 pass |

## Findings

- **IME feedback loop.** Every `set_ime_cursor_area` call makes the input method resend its
  preedit, even an empty one. If the app redraws on that event and sets the area again, it repaints
  without end, about 70 frames a second. The fix is to drop a preedit that equals the current one
  and to set the area only when the cursor moves. M5-37 must keep both rules.
- **Accessibility needs the bus switch.** accesskit_unix stays silent until the desktop's
  accessibility switch is on. That is normal for AT-SPI, but it means a test must switch it on in a
  private bus, as here. Otherwise it passes without checking anything.
- **The fallback frame.** Without winit's `wayland-csd-adwaita` feature, which would add a font
  rasteriser and more crates, GNOME gets sctk's plain fallback frame: no title text, basic buttons.
- **Size.** The trial's lock holds 296 outside packages, and 185 of them build on Linux.
  - 170 are new and vendored in full: about 152 MB unpacked. The biggest are icu_segmenter (23 MB),
    two linux-raw-sys versions (29 MB together), tracing and icu_segmenter_data.
  - About 64 of the 170 (about 10 MB) are needed only by the AT-SPI bridge (zbus and its async
    stack).
  - 111 packages are named in the lock only for other systems. They are vendored as manifests with
    no code (about 2 MB), listed in `.cargo/stubbed-crates.txt` and never built.
